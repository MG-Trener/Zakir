# Расписание 4 «И» класса

Школа-лицей № 37 имени Сырбая Мауленова. Разработчик: Рамир Закирович.

Сайт: https://mg-trener.github.io/Zakir/

Статический сайт на HTML, CSS и JavaScript по образцу MG-Trener/Artur и MG-Trener/alisa: неоновая неделя, выбор дня, подсветка текущего урока по времени Астаны, таймер перемен, напоминание за минуту до звонка и сезонные карточки каникул.

Расписание перенесено с предоставленной фотографии: 28 занятий, начало в 08:00; окончание в 12:45 по понедельникам, вторникам и четвергам, в 12:00 по средам и пятницам. Кабинеты в источнике отсутствуют.

## Изменение данных

- `script.js`: звонки (`periods`), предметы (`days`) и короткие названия для телефона (`shortNames`).
- `index.html`: школа, класс и подпись разработчика.
- `holiday-widget.js`: календарь каникул 2026/27, перенесённый из сайтов-образцов; обновляется отдельно на следующий учебный год.

## Проверка

Откройте `index.html` в браузере. Сборка и установка зависимостей не нужны.

```sh
node --check script.js
node --check holiday-widget.js
node tests/holidays.cjs
```

GitHub Pages публикует корень ветки `main`.
